Drop Cha's original photos here.

Name each file after its slot in data/media.json, with any of these extensions:
.avif .webp .jpg .jpeg .png

Example: hero-espresso-pour.jpg, bakery-taro-bread.webp, harc-machine.avif

Restart the dev server (or rebuild) and the labelled placeholder is replaced by the
photo, served as AVIF/WebP by next/image. Never use stock photos of other cafés.
